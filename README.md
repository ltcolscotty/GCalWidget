# GCalWidget

A productivity widget app that lets users link their google calendars and canvas calendars to a desktop widget on windows. This project is built primarily with with C# .NET10 and WINUI3, using some external libraries like the google APIs, and messagepack for storage and API interaction.

The existing implementation works for ASU primarily, if you'd like to add your own school or update the handling of classes take a look in [`uniRegexService-docs.md`](docs/uniRegexService-docs.md#how-do-i-add-my-own-school) to learn how to add your own school's regex configurations.
